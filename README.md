# sap-mdk-skills

Agent skills for SAP development, for Claude Code, Cursor, Codex and other coding agents.

## Skills

| Skill | Description |
|---|---|
| [`sap-mdk-apps`](skills/sap-mdk-apps) | SAP Mobile Development Kit (MDK) apps: project layout, metadata syntax, and the rules that prevent common failures on iOS, Android and the web |

## Installation

Install with the [skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills@1.7.0 add logalitech/sap-mdk-skills --skill sap-mdk-apps
```

`npx skills@1.7.0 add logalitech/sap-mdk-skills` installs every skill in the repository.
